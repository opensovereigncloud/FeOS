FeOS for Debian

The apt repository of FeOS's packages, signed, for Debian.

  • Debian 13 (trixie)
  • amd64

Set up the repository

  1. Trust the signing key

    sudo apt install -y curl
sudo curl -fsSLo /usr/share/keyrings/feos.gpg https://apt.fecode.dev/feos.gpg

    apt checks every index of this repository against the key. It has the fingerprint

    A420 0EF0 7FED 4845 F01C 446D 4CC1 E85A 1600 10A0

    which gpg --show-keys /usr/share/keyrings/feos.gpg shows. The key is also here armored.

  2. Add the repository

    sudo tee /etc/apt/sources.list.d/feos.sources >/dev/null <<'EOF'
Types: deb
URIs: https://apt.fecode.dev
Suites: stable
Components: main
Architectures: amd64
Signed-By: /usr/share/keyrings/feos.gpg
EOF

  3. Update the package lists

    sudo apt update

    apt now takes FeOS's packages from this repository.
